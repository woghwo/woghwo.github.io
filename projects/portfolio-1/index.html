🚗 프로젝트 개요

자율주행 환경에서 카메라와 LiDAR 데이터를 활용하여 객체를 탐지하고, 객체와의 거리를 기반으로 실시간 위험도를 계산하여 알리는 ADAS 시스템 데이터 전처리 자동화부터 모델 학습, 그리고 안정적인 거리 추정을 위한 하이브리드 알고리즘 구현을 담당함

  • GitHub: https://github.com/woghwo/ADAS_SESAC
  • 주요 기술: Python, PyTorch, Detectron2, OpenCV

🛠 주요 구현 및 문제 해결

1. 데이터 파이프라인 및 자동화 (Preprocessing)

  • 문제: 대용량 분할 압축 데이터의 효율적인 관리 필요.
  • 해결: 분할 압축 해제, 중복 제거, 2D Label/Image 추출, Train/Valid/Test 데이터 셋 분리를 수행하는 전처리 자동화 스크립트를 구현하여 협업 효율성을 높임

2. 데이터 불균형 분석 및 모델 최적화

  • 현상: 초기 베이스라인 모델 학습 후 추론 시, 배경(Background) 레이블이 이미지 전체를 덮거나 세그멘테이션 결과가 겹치는 현상 발생.
  • 원인 파악: 전체 데이터셋의 98% 이상이 배경 레이블인 심각한 데이터 불균형 확인.
  • 해결: 주요 객체 탐지에 집중하기 위해 배경 레이블을 제거하고 재학습을 진행하여 추론 정확도를 정상화
  • 추가 개선: 실제 영상 추론 시 ‘사람’에 대한 낮은 성능 확인 → 클래스 비율 분석 결과 사람 레이블이 1% 미만임을 파악하고, 사람 데이터 추가 보완의 필요성을 도출

3. 하이브리드 거리 추정 알고리즘 (Distance Estimation)

단순 모델 추론 값의 불안정성을 해결하기 위해 두 가지 방식을 결합

  • Model Prediction: Detectron의 Head를 추가하여, 객체 영역 내 최소 거리값 예측
  • Geometric Calculation: 카메라 보정(Calibration) 정보와 원근법을 이용해 Bounding Box 크기 기반의 기하학적 거리를 계산.
  • 결과: 모델 예측값과 기하학적 계산값의 평균을 최종 거리로 사용하여, 영상 데모 시 발생하는 거리 값 튀기(Jittering) 현상을 억제하고 안정성 향상

4. ROI 기반 실시간 위험도 판단 로직

단순 거리 기반 알림의 오검출(인접 차선 차량 등)을 방지하기 위해 주행 영역을 정의

  • 가상 사다리꼴 범위(ROI) 설정: 차선 폭과 주행 가능 영역을 고려한 사다리꼴 범위를 설정하여 범위 내 객체만 추적.
  • 위험도 3단계 분류:
    1. Danger: 객체 영역이 ROI의 30% 이상 침범(끼어들기) 혹은 거리 10m 미만.
    2. Caution: 안전거리(30m) 미만 유지 시 (10m ~ 30m).
    3. Safe: 그 외 정상 주행 상태.

📈 성과 및 배운 점

  • 데이터셋의 통계적 특성을 파악하는 것이 모델 성능 향상의 핵심임을 실무적으로 경험
